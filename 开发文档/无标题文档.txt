以下是基于与原始 C# 源码对比的详细代码审查。

---

## 总体评价

该 C++ 代码以**静态工具类**的形式翻译了 `MapData`，但原始 C# 的 `MapData` 是一个**有状态的实例类**，两者在架构设计上存在根本性差异，并引入了多处不存在于原始代码中的逻辑。

---

## 问题一：架构设计根本性错误——`MapData` 不是静态类

原始 C# 的 `MapData` 是一个完整的**实例类**，拥有大量实例状态字段（`ID`、`Name`、`Link`、`VRect`、`Scene`、`MiniMap` 等），`Load` 是一个**实例方法**，用于将地图数据填充到 `this` 中。 [1](#0-0) 

你的 C++ 版本将所有方法变为 `static`，丢失了完整的状态管理和对象生命周期。

---

## 问题二：`FindMapByID` 中手动计算偏移是多余且错误的逻辑

原始 C# 的 `FindMapByID` **只做三件事**：构造路径 → `FindWz` → `GetValueEx<Wz_Image>` → `TryExtract()`。 [2](#0-1) 

`Offset` 属性在 `Wz_File` 加载阶段已由框架计算完毕，`TryExtract()` 内部会直接使用 `this.Offset` 开流，无需调用方手动检查或重算。 [3](#0-2) [4](#0-3) 

你在 C++ 中添加的 `getOffset() == 0` → `calcOffset()` → `setOffset()` 这段逻辑在原始代码中**不存在**，且会产生误导。

---

## 问题三：第二个 `FindMapByID` 重载在原始代码中不存在

原始 C# 只有**一个** `FindMapByID` 重载（带 `out Wz_Node`）。你添加的带 `outImg` 参数的重载是自行发明的接口，且该重载在 `TryExtract()` 失败时仍然返回 `true`，逻辑上存在缺陷。 [2](#0-1) 

---

## 问题四：`PluginManager::RegisterStructures` 不存在

`PluginManager` 中**没有** `RegisterStructures` 这个方法。实际上，`WzFileFinding` 是一个 `internal static event`，由主程序 `MainForm` 在初始化时订阅，外部组件（包括插件）无法直接注册结构列表。 [5](#0-4) [6](#0-5) 

你的 `Load` 方法中调用 `PluginBase::PluginManager::RegisterStructures(structures)` 是**凭空捏造的 API**。

---

## 问题五：`Load` 方法严重不完整

原始 C# 的 `Load(Wz_Node, ResourceLoader)` 是一个实例方法，承担了加载整张地图（包括 `info`、`link` 跳转、`back`、8 个 Layer、`foothold`、`life`、`portal`、`ladderRope`、`miniMap` 等所有子结构）的全部职责。 [7](#0-6) 

你的 C++ `Load` 只是查找一个节点后直接返回，完全丢失了所有业务逻辑，也不接受 `ResourceLoader` 参数。

---

## 问题六：`GetMapLink` 未实现（自注释已承认）

原始代码在 `LoadInfo` 中通过 `infoNode.Nodes["link"].GetValueEx<int>()` 读取 `link`，并存入 `this.Link` 字段，随后在 `Load` 中判断是否进行链接跳转。 [8](#0-7) [9](#0-8) 

你的 `GetMapLink` 方法自注释已说明"暂时返回 -1，需要完善属性系统"，这是**未完成的功能**，不应在 Code Review 中通过。

---

## 问题七：`TryExtract` 的线程安全未处理

原始 `TryExtract()` 在读取时使用 `lock (this.WzFile.ReadLock)` 保证线程安全。 [10](#0-9) 

C++ 版本没有任何同步机制，在多线程场景下存在数据竞争风险。

---

## 问题八：头文件包含完整实现违反 C++ 惯例

所有方法实现写在 `.hpp` 头文件中，应拆分为 `.h`（声明）+ `.cpp`（实现），避免重复编译和链接问题。

---

## 总结对照表

| 问题点 | 原始 C# 行为 | C++ 代码行为 |
|---|---|---|
| 类设计 | 有状态实例类 | 纯静态工具类（丢失状态） |
| `FindMapByID` | 直接调用 `TryExtract()` | 额外手动计算 Offset（多余） |
| 第二个重载 | 不存在 | 自行添加，逻辑有缺陷 |
| `RegisterStructures` | 不存在此 API | 凭空调用 |
| `Load` 方法 | 加载全部地图子结构 | 仅查找节点后返回 |
| `GetMapLink` | 读取 link 字段，触发链接跳转 | 永远返回 -1（未实现） |
| 线程安全 | `lock(ReadLock)` | 无保护 |

## Notes

- 该 C++ 代码**不能**作为原始 C# `MapData` 的等价翻译使用，缺少了渲染所需的几乎全部业务逻辑。
- 如需完整移植，建议先保留 `MapData` 的实例类设计，再逐步移植 `LoadInfo`、`LoadBack`、`LoadLayer` 等子方法，同时为 `PluginManager` 实现基于回调/事件的 `WzFileFinding` 机制，而非 `RegisterStructures`。
- `Wz_Image::Offset` 属性由 `Wz_File` 的版本检测阶段统一设置，C++ 层不应在业务代码中重复计算。

        public bool TryExtract()
        {
            Exception ex;
            return TryExtract(out ex);

        public bool TryExtract(out Exception e)
        {
            if (!this.extr)
            {
                if (this.stream == null)
                {
                    this.stream = this.OpenRead();
                }

                bool disabledChec = this.WzFile?.WzStructure?.ImgCheckDisabled ?? false;
                if (!disabledChec && !this.chec)
                {
                    if (this.Checksum != this.CalcCheckSum(this.stream))
                    {
                        e = new ArgumentException("checksum error");
                        return false;
                    }
                    this.chec = true;
                }

                if (this.IsTextFormat())
                {
                    var reader = new WzStreamReader(this.stream);

                    try
                    {
                        lock (this.WzFile.ReadLock)
                        {
                            reader.BaseStream.Position = 0;
                            this.ExtractImgInTextFormat(reader, this.Node);
                            this.extr = true;
                        }
                    }
                    catch (Exception ex)
                    {
                        e = ex;
                        this.Unextract();
                        return false;
                    }
                }
                else
                {
                    if (!this.checEnc)
                    {
                        if (!this.IsLuaImage)
                        {
                            try
                            {
                                this.TryDetectEnc();
                                if (!this.checEnc)
                                {
                                    e = null;
                                    return false;
                                }
                            }
                            catch (Exception ex)
                            {
                                e = ex;
                                this.Unextract();
                                return false;
                            }
                        }
                    }

                    try
                    {
                        lock (this.WzFile.ReadLock)
                        {
                            var reader = new WzBinaryReader(this.stream, true);
                            reader.BaseStream.Position = 0;

                            if (!this.IsLuaImage)
                            {
                                ExtractImg(reader, this.Node);
                            }
                            else
                            {
                                ExtractLua(reader);
                            }
                            this.extr = true;
                        }
                    }
                    catch (Exception ex)
                    {
                        e = ex;
                        this.Unextract();
                        return false;
                    }
                }
            }
            e = null;
            return true;
        }
