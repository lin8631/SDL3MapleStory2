# MapleStory WZ PNG纹理渲染流程总结

从加载WZ文件到渲染纹理的完整流程：

## 1. 初始化阶段（examples/MapViewer_EnTT.cpp）

### 主循环入口
- `SDL_AppInit()`：初始化SDL3、创建窗口、设置OpenGL上下文
- `SDL_AppEvent()`：处理事件（键盘、鼠标、退出等）
- `SDL_AppIterate()`：主渲染循环

### 核心初始化步骤
1. **创建应用状态**：
   auto appState = std::make_shared<AppState>();
   appState->window = window;
   appState->renderer = renderer;
   
2. **加载WZ文件**：
   appState->wzLoader = std::make_shared<WzLibCpp::WzLoader>(dataPath);
   
3. **初始化地图数据**：
   appState->mapData = std::make_shared<MapRenderData>();
   appState->mapData->load(appState->wzLoader->getNode(), "Map01"); // 地图ID
   
4. **创建渲染器**：
   appState->mapRenderer = std::make_unique<MapRenderer>(appState->registry);
   appState->mapRenderer->setMapData(appState->mapData, wzPath);
   appState->mapRenderer->loadTextures(renderer); // 加载所有纹理
   

## 2. WZ文件加载与解析（Game/WzLib/）

### WZ文件结构
- **WzLibCpp::WzLoader**：主入口，负责加载和解析WZ文件
- **WzLibCpp::Wz_File**：表示WZ文件，包含头部信息和节点树
- **WzLibCpp::Wz_Node**：WZ文件的节点结构（树形结构）

### 关键解析流程
1. **读取WZ文件头部**：
   - `WzLibCpp::Wz_Header::load()`：解析WZ文件头部信息
   - 处理头部版本号解密（简单异或/变换）

2. **构建节点树**：
   - `WzLibCpp::Wz_File::extract()`：提取并解密WZ文件内容
   - 使用自定义AES实现（Game/WzLib/AES/）进行ECB模式解密
   - 密钥派生：从4字节IV生成连续的16字节块密钥流
   - 解密：密文字节与生成的密钥流字节进行异或操作
   - 解密后进行zlib解压缩得到实际数据

3. **构建节点对象**：
   - `WzLibCpp::Wz_Node`：表示WZ文件的每个节点
   - 支持节点属性（name, value, children等）访问
   - 关键类型：
     - `Wz_Value`：基础值类型（整数、字符串等）
     - `Wz_Image`：图像节点（包含PNG数据）
     - `Wz_Canvas`：画布节点
     - `Wz_Sound`：声音节点
     - `Wz_Vector`：向量数据

## 3. 地图数据加载（Game/MapRender/src/MapData.cpp）

### MapRenderData::load() 方法
1. **解析地图信息**：
   - 从WZ节点中读取地图基本信息（width, height等）
   - 解析不同类型的地图元素：
     - 背景（Back）：从 `Map/Back/` 路径读取
     - 瓦片（Tile）：从 `Map/Tile/` 路径读取
     - 对象（Obj）：从 `Map/Obj/` 路径读取
     - 其他元素：脚踏板(Foothold)、传送门(Portal)、生命点(Life)等

2. **背景数据加载**：
   
   for each backNode in mapNode->getNodes()["back"]->getNodes():
       BackItem item;
       item.name = backNode->getText(); // 背景名称
       item.bS = GetString(backNode->getNodes()->operator[]("bS"), ""); // 关键：背景文件名
       item.animFrame = GetInt(backNode->getNodes()->operator[]("ani"), 0); // 动画帧
       // 读取位置、偏移等信息
       backs.push_back(item);
   

3. **瓦片数据加载**：
   
   for each tileNode in mapNode->getNodes()["tile"]->getNodes():
       TileItem item;
       item.name = tileNode->getText();
       // 关键：使用"no"字段作为瓦片编号（修复前是"t"）
       item.no = GetInt(tileNode->getNodes()->operator[]("no"), 0);
       // 读取位置、图像编号等
       tiles.push_back(item);
   

4. **对象数据加载**：
   
   for each objNode in mapNode->getNodes()["obj"]->getNodes():
       ObjItem item;
       item.name = objNode->getText();
       // 关键：这些是字符串类型（修复前是整数）
       item.oS = GetString(objNode->getNodes()->operator[]("oS"), ""); // 对象集合
       item.l0 = GetString(objNode->getNodes()->operator[]("l0"), ""); // 第一级路径
       item.l1 = GetString(objNode->getNodes()->operator[]("l1"), ""); // 第二级路径
       item.l2 = GetString(objNode->getNodes()->operator[]("l2"), ""); // 第三级路径
       // 读取位置、图层等信息
       objs.push_back(item);
   

## 4. 纹理加载（Game/MapRender/src/MapRenderer.cpp & ResourceLoader.cpp）

### MapRenderer::loadTextures() 方法
1. **设置渲染器**：
   
   resourceLoader_->setRenderer(renderer);
   

2. **加载背景纹理**：
   
   for (auto& back : mapData_->backs) {
       loadBackTexture(renderer, back);
   }
   

3. **加载瓦片纹理**：
   
   for (auto& tile : mapData_->tiles) {
       loadTileTexture(renderer, tile);
   }
   

4. **加载对象纹理**：
   
   for (auto& obj : mapData_->objs) {
       loadObjTexture(renderer, obj);
   }
   

### 详细纹理加载流程

#### 背景纹理加载 - loadBackTexture()
1. **构建WZ路径**：`Map/Back/{bS}.img/{ani}/0`（根据WZComparerR2的结构）
2. **查找WZ节点**：`PluginBase::PluginManager::FindWz(path)`
3. **获取Wz_Image**：`objNode->getValue<Wz_Image>()`
4. **处理偏移**：计算并设置Wz_Image的偏移量
5. **提取图像**：`wzImg->tryExtract()`
6. **获取PNG数据**：
   - 首先检查提取后的节点是否为Wz_Png
   - 如果不是，递归查找子节点中的Wz_Png
   - 通常在第一个子节点中找到实际的PNG数据
7. **创建SDL纹理**：
   
   SDL_Texture* tex = resourceLoader_->loadTextureFromWzPng(renderer, wzPng);
   
8. **存储到ECS组件**：
   
   registry_.emplace<BackComp>(e, back.x, back.y, ..., tex, w, h);
   

#### 瓦片纹理加载 - loadTileTexture()
1. **构建WZ路径**：`Map/Tile/{no}.img/0`（no是瓦片编号）
2. 后续步骤与背景纹理相同：查找节点->获取Wz_Image->提取->获取Wz_Png->创建SDL纹理
3. **存储到ECS组件**：
   
   registry_.emplace<TileComp>(e, tile.x, tile.y, tex, w, h);
   

#### 对象纹理加载 - loadObjTexture()
1. **构建WZ路径（多种尝试）**:
   - 主路径：`Map/Obj/{oS}.img/{l0}/{l1}/{l2}/0`
   - 备用路径：使用反斜杠或省略某些路径层级
2. 后续步骤与背景/瓦片纹理相同
3. **存储到ECS组件**：
   
   registry_.emplace<ObjComp>(e, obj.x, obj.y, obj.layer, obj.z, tex, w, h);
   

### ResourceLoader::loadTextureFromWzPng() 方法
1. **从Wz_Png获取原始数据**：
   
   auto wzFile = std::dynamic_pointer_cast<Wz_File>(wzPng->getWzFile());
   if (wzFile && wzPng->getOffset() == 0) {
       wzPng->setOffset(wzFile->calcOffset(wzPng->getHashedOffsetPosition(), wzPng->getHashedOffset()));
   }
   if (!wzPng->tryExtract()) return nullptr;
   auto extracted = wzPng->getNode();
   if (!extracted || !extracted->getNodes()) return nullptr;
   auto firstChild = (*extracted->getNodes())[0];
   if (!firstChild) return nullptr;
   auto rawData = firstChild->getValue<Wz_RawData>();
   if (!rawData) return nullptr;
   

2. **创建SDL表面**：
   
   SDL_Surface* surface = SDL_CreateSurfaceFrom(
       rawData->width,
       rawData->height,
       SDL_PIXELFORMAT_ARGB8888,
       rawData->data.get(),
       rawData->width * 4
   );
   

3. **创建SDL纹理**：
   
   SDL_Texture* texture = SDL_CreateTextureFromSurface(renderer, surface);
   SDL_DestroySurface(surface);
   return texture;
   

## 5. 渲染循环（examples/MapViewer_EnTT.cpp）

### SDL_AppIterate() 主循环
1. **处理输入**：更新摄像机位置（基于键盘输入：WASD/方向键控制移动，Q/E控制缩放）
2. **清除渲染目标**：`SDL_SetRenderDrawColor(renderer, 0, 0, 0, 255); SDL_RenderClear(renderer);`
3. **渲染地图元素**：
   
   // 渲染背景（前半部分，isFront=false）
   appState->mapRenderer->renderBacks(renderer, appState->camera, false);
   
   // 渲染瓦片和对象（按图层0-7）
   for (int layer = 0; layer < 8; layer++) {
       appState->mapRenderer->renderTiles(renderer, appState->camera, layer);
       appState->mapRenderer->renderObjs(renderer, appState->camera, layer);
   }
   
   // 渲染背景（后半部分，isFront=true）
   appState->mapRenderer->renderBacks(renderer, appState->camera, true);
   
   // 渲染其他元素
   appState->mapRenderer->renderFootholds(renderer, appState->camera);
   appState->mapRenderer->renderPortals(renderer, appState->camera);
   appState->mapRenderer->renderLifes(renderer, appState->camera);
   
4. **呈现帧**：`SDL_RenderPresent(renderer);`

## 6. 渲染函数详解（Game/MapRender/src/MapRenderer.cpp）

### 渲染通用流程
所有渲染函数遵循相同模式：
1. 设置绘制颜色（对于线条和点）或使用纹理（对于图像）
2. 遍历相应的ECS组件视图
3. 计算屏幕坐标：考虑摄像机位置和缩放因子
4. 检查是否在视口内（裁剪不可见元素）
5. 调用SDL3渲染函数绘制元素

### 特殊渲染处理
- **背景渲染**：需要处理平铺（horizontal/vertical模式）和滚动效果
  - 根据背景类型计算需要绘制的瓦片范围
  - 对每个瓦片位置进行纹理绘制
- **瓦片/对象渲染**：直接绘制纹理到计算位置
- **脚踏板/传送门/生命点**：使用简单的几何图形（线条、矩形）进行标识

## 数据流总结


WZ文件磁盘
     ↓ (文件I/O)
WzLibCpp::WzLoader → WzLibCpp::Wz_File
     ↓ (解密: 自定义AES-ECB + 异或头部 + zlib解压)
WzLibCpp::Wz_Node 树结构
     ↓ (解析特定路径)
MapRenderData (backs/tiles/objs/vectors等)
     ↓ (构建WZ路径并查找节点)
MapRenderer::load*Texture() 方法
     ↓ (获取Wz_Png → 提取原始PNG数据)
ResourceLoader::loadTextureFromWzPng()
     ↓ (创建SDL_Surface → SDL_CreateTextureFromSurface)
SDL_Texture*
     ↓ (存储到ECS组件)
BackComp/TileComp/ObjComp 纹理字段
     ↓ (渲染循环中)
MapRenderer::render*() 方法
     ↓ (计算屏幕坐标 → SDL_RenderTexture)
最终帧缓冲
     ↓ (SDL_RenderPresent)
显示器


这个流程确保了：
1. WZ文件被正确解密和解压（使用自定义AES实现）
2. PNG图像数据被正确提取并转换为SDL纹理
3. 纹理与地图元素（背景、瓦片、对象）正确关联
4. 渲染循环根据摄像机位置和缩放正确绘制所有可见元素
5. 使用ECS架构高效管理游戏对象和组件
